# /front:review

Ao receber este comando, executar sem explorar o projeto e sem alterar nada. Listar todos os desvios do arquivo em relação a `.claude/rules/frontend/checklist-revisao.md`.

```
front:review
arquivo: [frontend/src/pages/<Feature>/<Arquivo>.tsx ou frontend/business/...]
```

Para auditoria de uma feature inteira, usar o agente `front-architecture-auditor`.
