# /front:refactorFormat

Ao receber este comando, aplicar `.claude/rules/frontend/formatacao.md` e `typescript.md` no arquivo indicado, sem mudar comportamento. Depois, dentro de `frontend/`, rodar `npm run format` e `npm run lint -- --fix` no arquivo (se as dependências estiverem instaladas).

```
front:refactorFormat
arquivo: [caminho em frontend/]
```
